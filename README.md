# 米居 MiJu

鸿蒙版米家移植 —— HarmonyOS NEXT 上的第三方米家客户端，基于开源项目「鸿米家」（[MrCashmere/miha_hm](https://github.com/MrCashmere/miha_hm)）二次开发。

使用米家账号扫码登录，即可在鸿蒙手机上管理家庭、房间与设备，控制米家生态里的智能硬件。

## 📱 目前已经实现的功能

- 所有设备列表（区分房间）与控制（大部分设备）
- 开关 / 灯光快捷操作
- 创建、管理智能场景
- 信息提醒
- 房间、家庭管理
- 外观自定义（背景图 / 字体）
- 适配沉浸光感
- 米家扫码登录（二维码过期自动续期）
- 数据备份与恢复

## ✨ 相比于原版

增加了不少功能：全页面下拉刷新（轻划即刷、带状态提示）、首页自动刷新间隔可调、开关乐观更新与动效、自定义背景去蒙版、纯净开屏等，目前已经基本可用了。

## ⚠️ 缺点

- 第一次只能扫码登录，暂不支持账号密码登录
- 不能添加新设备
- 目前仅支持手机

## 📲 下载

前往 [Releases](https://github.com/SKL-666666/MiHome-Client/releases) 下载现成的 hap 安装包（v1.1.0），侧载即可。

想自己折腾也可以从源码构建：用 DevEco Studio（HarmonyOS SDK，API 26+）打开项目，在 `File > Project Structure > Signing Configs` 配置自己的签名后构建安装。
