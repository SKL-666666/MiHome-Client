## 一、什么是 HAP / 侧载

- **HAP**（Harmony Ability Package）是鸿蒙应用的安装包格式，相当于安卓的 APK、iOS 的 ipa。一个应用可以由一个或多个 hap 组成，普通单模块应用就是一个 `xxx.hap` 文件。
- **侧载（Sideload）**：不经过应用市场，直接把安装包装到设备上。因为米居是第三方客户端、未上架华为应用市场，所以需要侧载安装。
- **已签名 vs 未签名**：
  - `signed`（已签名）：直接可装，**普通用户下载这个**；
  - `unsigned`（未签名）：装不上，需要开发者用自己的证书签名后才可安装。

## 二、准备工作

### 2.1 手机端设置

> 以 HarmonyOS NEXT（5.0 及以上）手机为例，不同版本入口名称略有差异。

**第一步：开启开发者模式**

1. 打开 **设置** → **关于手机**
2. 找到 **版本号**（HarmonyOS 版本），**连续快速点击 7 次**
3. 提示「您已进入开发者模式」

**第二步：打开 USB 调试**

1. 返回 **设置** → **系统与更新** → **开发人员选项**（开启开发者模式后才会出现这个菜单）
2. 打开 **USB 调试** 开关
3. （部分版本）同时打开 **「仅充电」状态下允许 ADB 调试**，避免每次插线都要确认

**第三步：连接电脑**

1. 用原装数据线（必须是能传数据的线，很多线只能充电）把手机连到电脑
2. 手机会弹窗 **「是否允许 USB 调试？」**，勾选「一律允许」并点 **允许**
3. 弹窗只弹一次的情况：拔插数据线、或重启手机后再看

> ⚠️ 如果手机一直不弹授权窗：换一根数据线、换一个 USB 口（优先接主板后面的 USB 口）、重启手机和电脑后再试。

### 2.2 电脑端环境

hdc（HarmonyOS Device Connector）是鸿蒙的设备连接工具，相当于安卓的 adb。有两种获取方式：

**方式 A：安装 DevEco Studio（一劳永逸，推荐）**

1. 到华为开发者官网下载并安装 DevEco Studio：
   `https://developer.huawei.com/consumer/cn/deveco-studio/`
2. 安装时勾选命令行工具，SDK 会自动就位
3. hdc 的位置（Windows 默认）：
   ```
   C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe
   ```

**方式 B：只下载命令行工具（不装 IDE）**

1. 到华为开发者官网 → 开发 → 工具 → 下载 **Command Line Tools**
2. 解压后里面有 `bin/hdc.exe`

**（可选但强烈建议）把 hdc 加入环境变量 PATH**

以 Windows 11 为例：

1. `Win + S` 搜索「编辑系统环境变量」→ **环境变量**
2. 在「系统变量」里找到 `Path` → **编辑** → **新建**
3. 粘贴 hdc 所在目录，例如：
   ```
   C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains
   ```
4. 一路确定，**重新打开**终端窗口生效
5. 验证：新开终端输入 `hdc version`，能打印版本号即成功

> macOS / Linux 用户：把 hdc 所在目录加入 `~/.zshrc` 或 `~/.bashrc` 的 `export PATH=...` 即可。

## 三、方式一：hdc 命令行安装（推荐）

### 第 1 步：确认设备已连接

```bash
hdc list targets
```

正常输出一行设备序列号，例如：

```
2PM0223922004263
```

- 输出 `[Empty]`：设备没连上，回到 [2.1](#21-手机端设置) 检查 USB 调试授权
- 输出多行：说明有多台设备，后续命令要加 `-t 序列号` 指定，例如 `hdc -t 2PM0223922004263 install ...`

### 第 2 步：安装 hap

打开终端（Windows 用 CMD 或 PowerShell 都行），`cd` 到 hap 文件所在目录，执行：

```bash
hdc install -r miju-v1.2.0-signed.hap
```

参数说明：

| 参数 | 作用 |
|---|---|
| `install` | 安装命令 |
| `-r` | 覆盖安装（已装过旧版本时保留数据升级；不加则已存在时报错） |
| 文件路径 | 也支持绝对路径，如 `hdc install -r C:\Downloads\miju-v1.2.0-signed.hap` |

安装成功输出：

```
[Info]App install path:... msg:install bundle successfully.
AppMod finish
```

### 第 3 步：启动应用

手机上直接点图标即可。也可以命令行拉起：

```bash
hdc shell aa start -b com.miju.client -a EntryAbility
```

### 无线安装（可选，免插线）

手机与电脑在同一 WiFi 下：

```bash
# 首次仍需数据线连接，切到无线监听
hdc tmode port 8731
hdc tconn 192.168.x.x:8731   # 换成手机的局域网 IP
hdc list targets              # 出现 IP:端口 即成功，之后可拔线
```

> 恢复 USB 模式：`hdc tmode usb`。手机重启后无线连接失效，需重连。

## 四、方式二：DevEco Studio 图形化安装

适合已经装了 DevEco Studio 的用户，全程点鼠标：

1. 打开 DevEco Studio（任意工程都行，没有工程就新建一个空的）
2. 把 `miju-v1.2.0-signed.hap` **直接拖进** DevEco Studio 窗口
3. 弹出安装确认框 → 选择已连接的设备 → 点 **Install / OK**
4. 等待底部进度条走完，提示安装成功

也可以：`File → Open` 选择 hap 文件，效果相同。

> 如果手机未连接，DevEco 顶部设备下拉框里是空的——先按 [2.1](#21-手机端设置) 处理连接。

## 五、方式三：第三方侧载工具

社区有一些图形化的鸿蒙侧载/管理工具（内置了 hdc，插上手机拖个 hap 就装）。使用时注意：

- 只从可信来源下载工具
- 原理都是调用 hdc，本质上和方式一没有区别
- 如果工具安装失败，请先用方式一手动执行一遍 `hdc install`，看具体报错再对症解决

## 六、常见问题排查

### ① `hdc list targets` 显示 `[Empty]`

按顺序检查：

1. 数据线是否支持数据传输（换线试试，这是最高频原因）
2. 手机「USB 调试」是否打开；插线后手机有没有弹授权窗，点「允许」
3. 电脑设备管理器里有没有异常设备（Windows 可能需要装华为手机驱动，装 DevEco Studio 一般自带）
4. 换 USB 口（台式机优先主板后置口），重启手机与电脑
5. 执行 `hdc kill` 后重试 `hdc list targets`

### ② `[Fail]ExecuteCommand need connect-key? please confirm a device by help info`

连接了多台设备（或残留了无线连接），hdc 不知道操作哪台。解决：

```bash
hdc list targets                 # 查看所有设备
hdc -t 设备序列号 install -r xxx.hap   # 用 -t 指定设备
# 或只保留一台：拔掉其他设备 / hdc tconn 断开无线
```

### ③ 安装报错 `install bundle failed` / 签名相关（如 code:9568322）

- **装的是 unsigned 包**：换 `signed` 版
- **签名与已安装版本不一致**：先卸载再装（数据会丢失，注意备份）：
  ```bash
  hdc uninstall com.miju.client
  hdc install -r miju-v1.2.0-signed.hap
  ```
- **降级安装**：新版本装了之后想装回旧版本，也必须先卸载

### ④ `install failed: version downgrad`

同上，先 `hdc uninstall 包名` 再安装。

### ⑤ 提示 `failed to open file` / 路径错误

- 确认终端当前目录下确实有该 hap（`dir` 或 `ls` 看一眼）
- 路径带空格或中文时用引号包起来：`hdc install -r "C:\我的下载\miju-v1.2.0-signed.hap"`
- 直接用绝对路径最稳妥

### ⑥ 安装成功但应用打不开 / 闪退

- 确认手机系统是 HarmonyOS NEXT（API 26+ 的包装不上老版本鸿蒙/安卓底层的设备）
- 卸载重装一次
- 到应用的反馈渠道提交日志

### ⑦ 手机弹窗一闪而过没来得及点允许

- 打开「一律允许 / 始终允许」再点允许，下次不再弹
- 或者先保持亮屏解锁状态再插线

### ⑧ `hdc` 不是内部或外部命令

hdc 没进 PATH。要么用完整路径调用：

```
"C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe" list targets
```

要么按 [2.2](#22-电脑端环境) 配置环境变量（配置后必须重开终端）。

### ⑨ 无线连接后拔线就断

`hdc tmode port` 设置的是临时模式，手机重启后失效。每次想用无线都要在 USB 连接状态下重新执行 `hdc tmode port 8731` 再拔线。

### ⑩ 公司电脑 / 网吧电脑装了驱动还是连不上

部分电脑 USB 口供电或策略受限，尝试：USB Hub 供电口、换电脑验证手机没问题、或使用无线调试方式。

## 七、常用 hdc 命令速查表

| 命令 | 作用 |
|---|---|
| `hdc list targets` | 列出已连接设备 |
| `hdc -t 序列号 <命令>` | 对指定设备执行命令 |
| `hdc install -r xxx.hap` | 覆盖安装 |
| `hdc uninstall 包名` | 卸载应用 |
| `hdc shell aa start -b 包名 -a Ability名` | 启动应用 |
| `hdc shell bm dump -n 包名` | 查看已安装应用信息（版本/权限） |
| `hdc shell hilog` | 查看系统日志（排错神器） |
| `hdc file send 本地路径 /data/...` | 推文件到设备 |
| `hdc kill` / `hdc start` | 重启 hdc 服务（连接异常时使用） |
| `hdc tmode port 端口` / `hdc tconn IP:端口` | 切换无线调试 |
| `hdc tmode usb` | 恢复 USB 模式 |

## 八、卸载与重装

```bash
# 卸载米居（会清除应用数据，包括登录状态）
hdc uninstall com.miju.client

# 重新安装
hdc install -r miju-v1.2.0-signed.hap
```

> 覆盖安装（`install -r`）不会清除数据；只有 uninstall 后再装才是全新状态。
